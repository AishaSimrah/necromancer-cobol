# Spooky theme ("The Crypt")

The theme must help the function, not just decorate.

- Metaphor: code is a body. Uploading = "Summon". Translating = "Resurrect". Passing tests = "It lives". Failing = "Cursed" with the exact input shown.
- Palette (starting point, finalize in Figma): near-black background, bone/off-white text, toxic green for passing, blood red for mismatches, dim purple for secondary UI.
- Typography: a monospace font for code and results; one gothic or serif display face for headings only.
- Match score is the hero element: a large number with a heartbeat or pulse animation that appears only after the tests actually ran.
- Mismatches appear as "ghosts" listing input, COBOL output, TypeScript output.
- Keep contrast accessible. Animations must be subtle and never block reading results.
- Screens: (1) The Crypt (pick/upload sample), (2) The Ritual (analysis + translation), (3) The Verdict (equivalence proof and match score).
